Herramientas de Migración

Guía de configuración

  1. Crea cuenta gratuita en supabase.com
  2. Crea un nuevo proyecto (región: West EU)
  3. Ve a SQL Editor y ejecuta el archivo supabase_schema.sql
  4. Ve a Settings → API y copia la URL y la clave anon
  5. Pega los valores arriba y pulsa Conectar
  6. Pulsa Subir datos locales para migrar los datos existentes
